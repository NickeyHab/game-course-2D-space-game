# game-course-2D-space-game

Project from game dev course game #3. Playable here: https://krabby12.itch.io/2d-space-shooter

2D Space shooter made with help of AI to create textures

Learned from course:
* create textures with AI
* use textures to make animations
* scrolling background
* movement
* create projectiles. Fire them, make them do damage, have enemies shoot.
* animate deaths with timeline
* use particle system
* animate level

Self added:
* level (auto) restart after time
* boss fight (+ extra boss you cant win)

Potential future features:
* have trigger events instead of using timeline to make the experience smoother
* healthbars
* maybe sfx
* item pickups like upgrades
